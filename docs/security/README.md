# PM Workbench security evidence pack

For the company security review. Each document states one property, says where in the code it
holds, and names the automated check that enforces it. Paths are relative to the repo root.

| Topic | Document | Enforced by |
|---|---|---|
| Where the GitHub token is stored and who can read it | [token.md](token.md) | `test/secrets.test.ts`, `test/service.test.ts`, `test/resilience.test.ts`; the Phase 5 end-to-end disk and log scan |
| No network destination but the configured GitHub host | [network.md](network.md) | `test/allowlist.test.ts`, `test/write.test.ts`, `test/product-service.test.ts`, `npm run smoke` |
| Every write is a branch plus a pull request; never a default branch | [../decisions/write-back.md](../decisions/write-back.md) | `test/write.test.ts` (network write guard and engine) |
| What is stored on the Mac, and where | [local-data.md](local-data.md) | n/a (inventory) |
| Electron hardening | [electron.md](electron.md) | `npm run smoke` (11 checks), electron-builder fuses |
| Dependencies and licences | [dependencies.md](dependencies.md) | generated by `npm run licenses` |
| No telemetry | [telemetry.md](telemetry.md) | network allow-list; dependency list |

**Running every check:**
```
npm install
npm run typecheck && npm test && npm run smoke
```
